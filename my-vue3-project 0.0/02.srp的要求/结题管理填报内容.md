## 一、总体评价（项目实施情况 · 核心）

本项目围绕「对话即服务」理念，完成了面向华南理工大学师生的校园 AI Agent 原型系统研发与真机验证。团队以 uni-app（Vue 3）构建「鲤工助手」移动端，以 FastAPI + LangGraph ReAct + 大模型 + 向量知识库构建本地 Agent 后端，实现了**校园服务导航、WebVPN 深链网关、本地课表导入与展示、每日签到、立绘/Emoji 鉴赏、华工智能体对话**等能力，并形成可复用的工程文档与开源自建说明。

对照立项设想，本项目**完成了核心技术路径验证**：将传统「按钮找功能」扩展为「自然语言理解 → 工具调度 / 知识检索 → App 执行动作或直接作答」的闭环。其中：

- **意图直达服务**：通过结构化 `actions[]` 协议，支持对话驱动跳转课表、查分、选课、教务及立绘等（含 WebVPN 先登录再进入），与首页服务入口同源、白名单可控。  
- **垂直场景减幻觉**：课表类问题不依赖编造，而由手机端按意图裁剪上传 `device_context`（今日/本周/完整课表摘要、当日签到等），后端注入本轮提示后作答。  
- **华工知识问答**：RAG 检索校园相关文档，前端支持 Markdown 渲染、思考过程折叠、长按复制、新对话清空会话等。

在落地策略上，团队根据接口开放与工程可行性做了合理纠偏：**不做 GUI 自动化**；成绩/选课等以深链打开官方页面为主；课表以用户授权导入的本地数据为准，而非强行对接未开放的教务开放 API。该纠偏保证了系统在真机上稳定可演示，同时仍对齐立项「懂华工、能办事」的目标。

立项中的二手书全域智能检索、评课系统深度打通后的通识课推荐、宿舍水电等主动推送等，受校园业务接口与数据条件限制，**未全部按原设想上线**；相关能力以知识库问答、服务跳转与后续扩展接口预留的方式部分覆盖。总体而言，项目形成了「可演示、可联调、可扩展」的校园 Agent 最小完备闭环，达到结题验收所要求的研究训练与成果交付水平，**建议结题结论：通过**。

## 二、人才培养情况（项目实施情况）

本项目为跨学院本科生团队协作课题（电子与信息学院、软件学院、计算机科学与工程学院等），在指导教师指导下完成从选题、方案设计、编码实现到真机联调与文档沉淀的完整科研训练链条。

### （1）能力培养

| 维度 | 训练内容与收获 |
| --- | --- |
| 工程实践 | uni-app / Vue 3 多端 App 开发；原生 tabBar 与页面路由规范；WebView / WebVPN 网关；本地存储与课表解析导入 |
| AI Agent | LangGraph ReAct、工具调用、服务目录白名单、前后端动作协议；RAG 向量库构建与检索增强生成 |
| 产品与科研方法 | 需求调研与场景优先级；「能跳转 / 能读本地课表 / 能答知识」分阶段验收；隐私边界（课表默认不出手机） |
| 协作与表达 | 跨学院分工（前端、Agent 后端、知识整理、测试与文档）；定期学术沙龙与技术研讨；架构说明与开源 README 撰写 |

### （2）组织方式

- 固定例会 + **组内学术沙龙 / 技术研讨**，议题覆盖工具调用协议、RAG 幻觉抑制、WebVPN 体验、`device_context` 裁剪、真机 `adb reverse` 联调等，并形成纪要与待办。  
- 关键接口变更实行「前后端服务目录对齐 + 重启后端 + 真机回归」流程，强化工程规范意识。  
- 鼓励成员独立排查联调问题（网络、权限、存储键、模型拒答/乱跳等），提升问题定位与文档阅读能力。

### （3）育人效果简述

通过本项目，成员将大模型应用从「会聊天」推进到「会调用工具、会约束事实边界、会在手机端闭环执行」，较好地落实了 SRP「以学生为主体、在科研中学习」的培养目标；形成的系统与文档亦可作为后续课程设计、实验室展示或个人作品集素材。

## 三、项目取得成果（项目实施情况）

> 说明：以下仅写实际已完成或正在推进的成果；**不含**未开展的论文发表、学科竞赛获奖等。

### （1）可运行系统（主要成果）

完成一套可在安卓真机运行的「鲤工助手」校园服务 App，并与本地「华工智能体」后端联调成功，主要功能包括：

1. **校园功能导航**：常用/更多服务网格；普通外链与 `*.webvpn.scut.edu.cn` 深链分流；WebVPN 门户先登录再进目标页。  
2. **每日签到**：按自然日一次；随机华工助手 Emoji + 配语；累计签到天数。  
3. **我的课表**：本地存储周课表；App 端经 WebVPN 登录后注入脚本提取并导入教务课表；支持校区时间模式与开学周设置。  
4. **华工智能体（AI Agent）**  
   - 知识库问答（RAG）；  
   - 对话驱动跳转（`actions[]`：`switch_tab` / `navigate_to` / `open_campus_web`）；  
   - 按意图注入本地课表与当日签到上下文；  
   - 新对话重置、长按复制、连不上后端时引导打开开源配置说明。  
5. **立绘 / Emoji 鉴赏**：用户页入口；立绘多卡跟手翻页；Emoji 原图与配语浏览。

技术架构要点（详见《项目架构说明》）：前端 `src/` + 原生 tabBar；后端 `00.my-agent/`（`/chat`、`/chat/reset`）；工具含知识检索与 `open_campus_service`；真机联调需 USB 调试与 `adb reverse tcp:8000 tcp:8000`。
