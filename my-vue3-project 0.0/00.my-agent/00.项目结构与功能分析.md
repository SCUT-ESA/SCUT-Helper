# 00.my-agent · 项目结构与功能分析

本文档基于当前仓库**实际源码**梳理，描述「华工校园智能体」后端的目录结构、技术架构、核心功能、API、数据流与启动方式。若与方案说明文档（`🚀 本地 Agent 服务 + 网页对话（完整方案）.md`）有出入，**以源码为准**。

---

## 1. 项目概览

| 项 | 说明 |
| --- | --- |
| 定位 | 华南理工大学校园助手 Agent：知识库问答 + Web 对话界面 |
| 技术栈 | Python + FastAPI + LangGraph (ReAct) + LangChain + Chroma + 本地 BGE 向量模型 |
| LLM | MiniMax-M2.1（OpenAI 兼容接口，经 `OPENAI_BASE_URL` 调用） |
| 向量检索 | Chroma 持久化目录 `vectordb/` + `BAAI/bge-large-zh-v1.5`（本地离线） |
| 前端 | 静态 HTML（`frontend/index.html`），双栏看板式对话 UI |
| 运行方式 | 本地 `uvicorn`（8000）+ `python -m http.server`（8080） |

**一句话**：用户在网页提问 → FastAPI `/chat` → LangGraph ReAct Agent 按需调用知识库工具 → MiniMax 生成回答 → 返回前端渲染（支持 Markdown / `<think>`）。

## 4. 核心模块详解

### 4.1 `agent.py` — Agent 核心

- 使用 `create_react_agent` 创建 ReAct 智能体（可决定是否调用工具）。
- 模型：`ChatOpenAI(model="MiniMax-M2.1", temperature=0.3)`，凭 `.env` 中的 `OPENAI_BASE_URL`、`OPENAI_API_KEY`。
- 记忆：`MemorySaver` 内存 Checkpointer；同一 `thread_id` 可延续多轮对话。
- 系统提示要点：
  - 华工官方校园助手 / 温柔知性学姐人设
  - **知识库最高优先级**：有则必须用库内内容，无则答「超出能力范围」
  - 禁止追问「你是不是华工学生」
  - 回答偏 Markdown、少 emoji；有链接时附温馨提示

### 4.2 `app.py` — HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/chat` | Body: `{ "message": str, "thread_id"?: str }` → `{ "thread_id", "answer" }` |
| `GET` | `/chat/stream` | Query: `message`、`thread_id`；SSE 推送 `{content}` 片段，结束发 `[DONE]` |

行为细节：

- 未传 `thread_id` 时自动 `uuid4()`，便于多轮会话。
- `/chat` 取 messages 中最后一条 `type == "ai"` 的 `content` 作为 `answer`。
- 已开 CORS `allow_origins=["*"]`，方便本地静态页跨域访问。

### 4.3 `tools/knowledge.py` — 知识库工具

- 启动时加载 `vectordb` + BGE embedding（`HF_HUB_OFFLINE=1`，本地缓存）。
- 暴露 LangChain `@tool`：`search_knowledge_base(query)`。
- `similarity_search(query, k=5)`，拼接 `[来源：path]` + 文本块返回给 Agent。

### 4.4 `build_vectordb.py` — 向量库构建

流水线：

1. `DirectoryLoader("data/documents/", "*.txt", UTF-8)`
2. `RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)`
3. `HuggingFaceEmbeddings(BAAI/bge-large-zh-v1.5, cpu, local_files_only)`
4. `Chroma.from_documents(..., persist_directory="vectordb")`

知识文档变更后需**删除旧 `vectordb` 再重建**，并重启后端，新内容才会生效。

### 4.5 `frontend/index.html` — Web 对话 UI

- 布局：左栏全身形象 + 状态卡；右栏消息流 + 输入区。
- 请求：`POST /chat`，JSON `{ message }`（**未传 thread_id**，因此每次请求可能是新会话，多轮记忆在网页端当前实现中较弱）。
- 渲染：`marked` 解析 Markdown；支持模型输出的 `<think>...</think>` 折叠为「深度思考」面板。
- 资源：`03.全身图.jpg`、`04.半身图.jpg`；`github.css` 若缺失不影响主流程（样式以内联 CSS 为主）。

### 4.6 `一键启动脚本.bat`

顺序：

1. 新窗口：`venv` + `uvicorn app:app --reload --host 127.0.0.1 --port 8000`
2. 新窗口：`python -m http.server 8080`
3. 浏览器打开：`http://127.0.0.1:8080/frontend/index.html`

关闭两个 CMD 窗口即可停止服务。

## 6. 配置与环境

### 6.1 `.env`（变量名，勿把真实 Key 写进文档/仓库）

| 变量 | 作用 |
| --- | --- |
| `OPENAI_API_KEY` | MiniMax（或兼容）接口密钥 |
| `OPENAI_BASE_URL` | 兼容接口地址（当前为 MiniMax） |
| `MINIMAX_GROUP_ID` | 预留；当前 `agent.py` 未读取 |

### 6.2 HuggingFace / 模型缓存

- `HF_ENDPOINT=https://hf-mirror.com`（国内镜像）
- `HF_HUB_OFFLINE=1` + `local_files_only=True`：要求本机已缓存 `BAAI/bge-large-zh-v1.5`，否则构建/启动检索会失败。

## 7. 端到端数据流

```
用户输入
  → frontend fetch POST /chat
  → FastAPI 生成/复用 thread_id
  → agent.invoke({ messages: [("user", message)] }, config)
  → ReAct 循环：
       · 模型可能调用 search_knowledge_base
       · 工具从 Chroma 取 Top-5 片段
       · 模型按 system prompt 组织最终回答
  → 返回 { thread_id, answer }
  → 前端 parseAndRenderMessage（Markdown + think）
```

流式路径（已实现、前端未接）：

```
GET /chat/stream?message=...&thread_id=...
  → agent.astream_events → on_chat_model_stream → SSE data: {"content":"..."}
  → data: [DONE]
```

## 10. 启动与维护速查

### 日常启动

- 推荐：双击 `一键启动脚本.bat`
- 或手动：
  1. `venv\Scripts\activate`
  2. `uvicorn app:app --reload --host 127.0.0.1 --port 8000`
  3. 另开终端：`python -m http.server 8080`
  4. 浏览器：`http://127.0.0.1:8080/frontend/index.html`
- 健康检查：打开 `http://127.0.0.1:8000/docs` 查看 FastAPI 文档。

### 更新知识库

1. 编辑/新增 `data/documents/*.txt`（UTF-8）
2. 删除旧库：`rmdir /s /q vectordb`
3. `python build_vectordb.py`
4. 重启 uvicorn

## 11. 风险与改进建议

1. **前端未传 `thread_id`**：多轮上下文难以利用；建议前端持久化 `data.thread_id` 并在后续请求带回。
2. **流式接口未用**：体验上可改接 `/chat/stream`，边生成边渲染。
3. **方案文档过时**：E2B、OpenAI Embedding 等描述易误导新人；维护时以本分析与源码为准。
4. **安全**：`.env` 含密钥，勿提交 Git；CORS `*`、无鉴权仅适合本机演示。
5. **检索质量**：`campus.txt` 过短；长文 `software-study-guide.txt` 切块策略可再调（chunk / overlap / k）。
6. **对接 App**：若接入鲤工助手，建议抽环境配置（Base URL）、统一错误处理，并考虑 App 真机访问本机 IP 而非 `127.0.0.1`。
