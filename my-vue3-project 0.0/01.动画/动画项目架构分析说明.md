# 鲤工助手 · 宣传动画项目架构分析说明

本文档基于 `01.动画/` **当前**代码与素材梳理（含 2026-07 新增 Agent 真机演示图与更新截图），说明定位、目录、分镜实现、素材约定与渲染方式。

---

## 1. 项目概览

| 项 | 说明 |
| --- | --- |
| 所属仓库 | 鲤工助手旁路目录 `01.动画/` |
| 定位 | Manim 程序化 **App 宣传片**（非 App 运行时依赖） |
| 产品名 | 鲤工助手 |
| 视觉基调 | 黑底科技风；青蓝 `#00F0FF` / 紫 `#8A2BE2`；霓虹、HUD、Glitch、矩阵雨 |
| 目标时长 | 约 **1 分 45 秒～2 分 10 秒**（见 `具体要求：.md`） |
| 引擎 | Manim Community |
| 主场景类 | `LiGongAssistant` |
| 主力脚本 | **`ligong2.py`** |
| 策划 | `具体要求：.md`（修订版分镜） |

与主 App：独立渲染；截图 / Logo / 立绘 / Emoji 展示能力。Agent 段优先用 **真机对话截图**（`Agent功能演示0/1.jpg`），对齐真实「跳转 + 读表 + 知识库」。

## 2. 技术架构

```
具体要求：.md（分镜）
        │
        ▼
ligong2.py  LiGongAssistant.construct()
  intro → problem → solution → features

  → call_to_action → outro → credits
        │
   ┌────┼────┐
   ▼    ▼    ▼
assets/  Manim   media/

```

```bash
# 在 01.动画/ 下
manim -pql ligong2.py LiGongAssistant   # 预览
manim -pqh ligong2.py LiGongAssistant   # 1080p
```

## 6. `ASSETS` 字典（与代码同步）

以 `ligong2.py` 顶部为准，关键键：

| 键 | 文件 |
| --- | --- |
| `logo` / `art_half` / `art_full` / `art_sketch_*` | logo · 04半身 · 03全身 · 01/02草图 |
| `worried` | `苦恼.jpg` |
| `home_before` / `home_after` | 签到前/后首页 |
| `agent` | `智能体页面.jpg` |
| `agent_demo_0` / `agent_demo_1` | **Agent功能演示0/1.jpg** |
| `timetable` / `import_tt` / `user` | 课表 · 导入 · 用户 |
| `art_about` / `emoji_gate` / `emoji_view_*` | 立绘说明 · Emoji 入口/鉴赏 |
| `qr` / `bgm` | 二维码 · 星际穿越.mp3 |
| `emoji_00`… | `00.emoji/*.jpg` |

缺文件时 `safe_image` 显示 `ASSET MISSING` 占位，不中断渲染。

## 7. 美术约定

1. 底色 `#0A0A12`；标题蓝→紫渐变；问题段才用警示红。  
2. 单镜特效 ≤2～3 种；Agent 段以**大图真机对话**为主。  
3. 立绘/Emoji 保持原图清晰度。  
4. 中文 `Microsoft YaHei`；角标等宽 `Courier`。  
5. 人物出镜：开场半身 → 签到陪伴 → Agent 页头像（截图内）→ 立绘定妆 → 结尾全身。

## 9. 与历史版差异

| 维度 | 旧宣传片 / 旧架构描述 | 现行 |
| --- | --- | --- |
| 卖点 | 聚合导航 | 导航 + 签到 Emoji + 课表 + **Agent** + **立绘** |
| Agent | 抽象口号或手绘气泡 | **真机演示0/1** |
| 路径 | 曾用 `logo.png`/`首页.jpg` 等短名 | **`ASSETS` 对齐中文文件名** |
| 调用链 | 含 `navigation`+`tech_advantages` | `features` 内含导航；`agent_showcase`+`art_gallery` 替换旧科技愿景墙 |
