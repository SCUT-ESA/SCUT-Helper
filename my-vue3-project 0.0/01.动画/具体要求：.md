# 鲤工助手 · 宣传动画脚本编排（修订版）

> **本稿性质**：Manim 宣传片的**分镜 / 文案 / 素材 / 配乐规划**，**不写代码**。  
> **时长目标**：约 **1 分 45 秒～2 分 10 秒**（可按成片微调 ±10s）。  
> **美术延续**：黑底科技风；主色 **青蓝 `#00F0FF` / 紫 `#8A2BE2` / 点缀青绿**；霓虹描边、HUD 瞄准角、网格、粒子、Glitch、矩阵雨等与现有 `ligong2` 成片气质一致。  
> **产品依据**：当前前后端（校园导航 + 每日签到 Emoji + 本地课表 + 华工智能体 Agent + 立绘/Emoji 鉴赏），不以旧版「仅导航截图」为准。

---

## 0. 叙事总纲（先读这段）

旧片问题：当时没有**华工人设形象**，也没有**立绘鉴赏 / 表情包**，更没有能办事的 **Agent**，卖点停在「聚合入口」，观感容易过时。

新片主线一句话：

> **校园入口太散 → 鲤工助手把路收拢 → 有脸有温度（立绘 / Emoji）→ 华工智能体能跳转、能读你的课表、能答华工知识，而不是无脑人机。**

情绪曲线：

```
紧张杂乱（问题）
  → 清爽降噪（解决方案 + 导航/课表）
  → 俏皮共鸣（签到 Emoji）
  → 能力高光（Agent 三连击）
  → 审美与人格（立绘说明 + 表情包）
  → 信任收束（下载 / Slogan / 致谢）
```

**品牌角色**：华工助手立绘（半身 / 全身 / 草图）是**视觉锚点**，不是装饰贴图；Emoji 是她的「日常表情」；智能体对话里可短暂以半身像作头像出现，强化「她在帮你办事」。

**绝对不要拍成**：通用 AI 广告、堆砌未来口号、GUI 全自动替你点教务。Agent 卖点对齐真实能力——**对话驱动跳转 + 本地课表上下文 + 华工知识库**。

## 2. 分镜详细要求

### 2.1 开场 · 系统唤醒（0:00–0:12）

**视觉**

- 黑底浮现**透视蓝紫网格**（远→近或缓慢推移）。
- 粒子 / 光点从四周汇聚；可选叠加虚线旋转环（延续现有霓虹环气质）。
- 汇聚成 **App Logo**（适当放大；原图约正方形即可）。
- Logo 下方标题：**「鲤工助手」**，无衬线，蓝→紫渐变，轻 `Flash` / 霓虹描边。
- Logo 侧后方或下方短暂浮现 **半身立绘剪影→清晰半身**（透明度由低到高），暗示「有人在」。

**动画**

- 网格入场 → 粒子聚合 → Logo 弹性放大 → 标题写出 → 立绘半透明伴生 → 整组利落收束切下一段。

**文案（可选极短，可不念）**

- 终端风角标滚动（可保留旧片趣味）：`INITIALIZING…` / `SYSTEM ONLINE`

**配乐**

- 低音前奏渐强；Logo 定格时加短促「嗖」或合成器扫频。

### 2.2 问题引入 · 碎片化校园（0:12–0:26）

**视觉**

- 保持黑底；灰暗杂乱「入口碎片」（圆角卡片 / 假链接块 / 十六进制乱码），警示红描边。
- 碎片抖动、错位、破碎消散（Glitch：青 / 红色差层）。

### 2.4 日常能力蒙太奇（0:40–1:00）

采用**连续切换或三卡 HUD 排列**，每段约 5–7 秒；卡片带霓虹边与四角瞄准框（延续旧美术）。

#### A. 每日签到（Emoji 高光）

- **前**：首页未签到态。
- **点击反馈**：「签到中」感（短加载光效即可）。
- **后**：签到结果——**随机华工 Emoji 大图 + 配语** + 累计天数文案氛围（「我的华工 · 签到的总是最好的」可作小字）。
- 配语示例（择 1 条上屏，勿堆字）：
  - 「爱心发射～先哄好你，再偷偷搞小恶作剧ฅ●ω●ฅ」
  - 或「课桌限定发呆模式开启，老师可别抓我哟」

#### B. 校园导航（一键直达）

- 首页功能网格高亮若干入口（查分 / 选课 / WebVPN / 一卡通等）。
- 可用「散点 → 收束到手机」的拓扑光点（旧片导航段可复用气质），强调**聚合**而非罗列 LOGO 墙。
- 短句：「常用服务，少绕弯路。」

#### C. 我的课表

- **左**：课表周视图；**右**：导入页或导入成功态（体现「可从教务提取到本地」）。
- 短句：「课表在手机里，不在收藏夹迷宫里。」

**配乐**

- 轻快电子节拍；每切一段可加极短切换音。

### 2.5 高光段落 · 华工智能体 Agent（1:00–1:32）★本片灵魂

**设计原则**

- 用**真机对话截图**讲清 Agent 与「只会聊天的机器人」的差别（优先 `Agent功能演示0/1.jpg`，辅以欢迎页 / 课表页）。
- 霓虹手机框 + HUD 角包装截图；背景可叠浅矩阵雨，**不要**盖过对话可读性。
- 动作标签（如 `action: open_campus_web`）半透明一闪即可，勿抢戏。

#### Beat ① 对话即跳转（约 8–10s）

- 先闪 **智能体欢迎页**（`智能体页面.jpg`）。
- 切到 **`Agent功能演示0.jpg`**：真实对话含「我要选课」→「正在帮你打开自主选课…」（深度思考折叠条可保留）。
- 短切 **`课表页面.jpg`**：补充「也能一键打开课表 Tab」。
- 上屏：「对话即跳转：我要选课 → 打开页面」

#### Beat ② 读懂你的课表（约 10–12s）

- 仍以 **`Agent功能演示0.jpg`** 为主：用户「我今天什么课？」→ Agent 按本地课表列出节次 / 课程 / 教室 / 老师。
- 对比：灰掉并打叉「根据一般大学生作息……」。
- 上屏：「读懂你的课表」+「课表在你手机里——Agent 按你的数据答，不编造。」

#### Beat ③ 华工知识库，拒绝空心客服（约 8–10s）

- 切到 **`Agent功能演示1.jpg`**：知识库式长答（如学习方法 / 线代建议），体现「懂华工」而非空心客服。
- 反差：灰掉「请咨询贵校教务处。」
- 上屏金句：**「懂华工的智能体，不是万能复读机。」** / 「华工知识库，拒绝空心客服」

**本段结尾收束句（建议保留）**

- 「跳转 · 读表 · 知识库——华工智能体，能聊天，更能办事。」

**配乐**

- 推向本片第一个小高潮；Beat ② 回答落地时给「确认」感音效；Beat ③ 可略宏大，但仍克制。

## 4. 美术与镜头语言规范（延续优秀旧风格）

1. **底色**：近黑 `#0A0A12`，忌大面积纯白商业风。
2. **主色**：青蓝 + 紫渐变标题；点缀青绿数据流；问题段才用警示红。
3. **组件语言**：霓虹多层描边、HUD 四角、扫描线、虚线环、粒子、短 Glitch——服务于叙事，单镜特效不超过 2～3 种同时抢戏。
4. **字体**：中文无衬线（如微软雅黑 / 思源）；终端角标用等宽英文。
5. **截图原则**：用真机 UI；立绘 / Emoji **保持高清**，不为「顺滑」模糊成片。
6. **人物出镜**：开场伴生、解决方案同框、Agent 头像、立绘专段、结尾定妆——形成记忆锚点。
7. **信息密度**：Agent 段字要少、对话要大；立绘理念只保留金句，完整创作说明留给 App 内阅读。
