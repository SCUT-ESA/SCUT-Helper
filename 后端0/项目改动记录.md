## 详细改动列表

### 1. 修改 `backend/app/config/db_config.py`

#### 改动内容：
- **添加导入**：
  - `from pathlib import Path` - 用于路径处理
  - `from urllib.parse import quote_plus` - 用于URL编码

- **修复 `.env` 文件加载路径问题**：
  ```python
  # 获取app目录路径（db_config.py在app/config/目录下，所以需要向上两级）
  BASE_DIR = Path(__file__).resolve().parent.parent
  # 加载 .env 文件（在app目录下）
  env_path = BASE_DIR / '.env'
  load_dotenv(env_path)
  ```
  **原因**：原代码使用 `load_dotenv()` 不指定路径，导致在不同目录启动服务时找不到 `.env` 文件。

- **修复密码特殊字符问题**：
  ```python
  # 对密码进行URL编码（处理特殊字符如@等）
  encoded_password = quote_plus(DB_PASSWORD) if DB_PASSWORD else ""
  ```
  **原因**：数据库密码中包含 `@` 符号时，会被误解析为连接字符串的分隔符，导致连接失败。

- **添加调试信息**：
  ```python
  print(f"正在加载 .env 文件: {env_path}")
  print(f".env 文件是否存在: {env_path.exists()}")
  print(f"DB_USER: {DB_USER}")
  print(f"DB_PASSWORD: {'*' * len(DB_PASSWORD) if DB_PASSWORD else 'None'}")
  print(f"DB_HOST: {DB_HOST}")
  print(f"DB_PORT: {DB_PORT}")
  print(f"DB_NAME: {DB_NAME}")
  ```
  **原因**：便于排查配置问题和验证环境变量是否正确加载。

### 2. 创建 `backend/app/init_db.py`

#### 文件说明：
用于通过 SQLAlchemy ORM 自动创建数据库表的初始化脚本。

#### 使用方法：
```bash
cd backend/app
python init_db.py
```

#### 功能：
- 自动读取所有模型定义
- 使用 `Base.metadata.create_all()` 创建表结构
- 支持异步数据库操作

---

### 3. 创建 `backend/app/init_db_simple.py`

#### 文件说明：
更简单直接的数据库初始化脚本，直接执行 SQL 语句创建表。

#### 使用方法：
```bash
cd backend/app
python init_db_simple.py
```

#### 功能：
- 直接执行 SQL 创建表
- 不依赖 ORM 模型定义
- 更可靠，适合快速初始化

#### SQL 内容：
```sql
CREATE TABLE IF NOT EXISTS users (
    user_id      CHAR(36)     NOT NULL PRIMARY KEY,
    username     VARCHAR(50)  NOT NULL,
    account_name VARCHAR(20)  NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## 解决的问题

### 问题1：数据库连接失败
- **错误信息**：`Can't connect to MySQL server on '1019667310@localhost'`
- **原因**：
  1. `.env` 文件路径不正确，环境变量未正确加载
  2. 密码中包含 `@` 符号，导致连接字符串解析错误
- **解决方案**：
  1. 使用 `Path` 指定 `.env` 文件的完整路径
  2. 使用 `quote_plus()` 对密码进行 URL 编码

### 问题2：数据库不存在
- **错误信息**：`Unknown database 'scut-helper'`
- **解决方案**：手动创建数据库或使用 `init.sql` 文件

### 问题3：表不存在
- **错误信息**：`Table 'scut_helper.users' doesn't exist`
- **解决方案**：创建了 `init_db.py` 和 `init_db_simple.py` 脚本用于初始化表结构

## 配置要求

### 环境变量配置（`.env` 文件）
位置：`backend/app/.env`

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=scut_helper
DB_CHARSET=utf8mb4
```

**注意事项**：
- 如果密码包含特殊字符（如 `@`、`#`、`%` 等），代码会自动进行 URL 编码
- 确保数据库服务已启动
- 确保数据库已创建（可使用 `init.sql` 或手动创建）

## 项目启动流程

1. **创建并激活 Conda 环境**：
   ```bash
   conda create -n scut_helper python=3.11 -y
   conda activate scut_helper
   ```

2. **安装依赖**：
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

3. **配置环境变量**：
   ```bash
   cd app
   copy .env.example .env
   # 编辑 .env 文件设置数据库信息
   ```

4. **初始化数据库**（首次运行）：
   ```bash
   python init_db_simple.py
   # 或使用 MySQL 客户端执行 init.sql
   ```

5. **启动服务**：
   ```bash
   uvicorn main:app --reload
   ```
