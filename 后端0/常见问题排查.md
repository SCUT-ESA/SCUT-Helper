# 常见问题排查

### 问题1：找不到 `.env` 文件

**症状：** 启动时提示找不到环境变量或数据库连接失败

**解决方案：**

- 确认文件在 `backend/app/.env` 路径下
- 确认文件名是 `.env`（不是 `.env.txt`）
- Windows 系统注意文件扩展名，确保不是 `.env.txt`

### 问题2：数据库连接失败

**症状：** 错误信息：`Can't connect to MySQL server`

**解决方案：**

1. 检查 MySQL 服务是否启动：

   ```bash
   # Windows
   net start MySQL80
   # 或检查服务状态
   sc query MySQL80
   ```

2. 检查 `.env` 文件中的配置：

   - `DB_HOST` 是否正确（通常是 `localhost`）
   - `DB_PORT` 是否正确（通常是 `3306`）
   - `DB_USER` 是否正确（通常是 `root`）
   - `DB_PASSWORD` 是否正确

3. 测试 MySQL 连接：

   ```bash
   mysql -u root -p
   ```

### 问题3：数据库不存在

**症状：** 错误信息：`Unknown database 'scut_helper'`

**解决方案：**

- 按照 Step6 创建数据库
- 确认数据库名称与 `.env` 文件中的 `DB_NAME` 一致

### 问题4：表不存在

**症状：** 错误信息：`Table 'scut_helper.users' doesn't exist`

**解决方案：**

- 按照 Step7 初始化数据库表
- 或手动执行 SQL 创建表

### 问题5：端口被占用

**症状：** 启动时提示端口 8000 已被占用

**解决方案：**

1. 修改启动端口：

   ```bash
   uvicorn main:app --reload --port 8001
   ```

2. 或关闭占用 8000 端口的程序：

   ```bash
   # Windows 查看占用端口的进程
   netstat -ano | findstr :8000
   # 然后使用任务管理器结束对应进程
   ```

### 问题6：依赖安装失败

**症状：** `pip install` 时出现错误

**解决方案：**

1. 确保已激活 conda 环境：

   ```bash
   conda activate scut_helper
   ```

2. 升级 pip：

   ```bash
   python -m pip install --upgrade pip
   ```

3. 如果使用精简版依赖仍有问题，可以尝试完整版：

   ```bash
   pip install -r requirements.txt
   ```

### 问题7：账户名已存在

**症状：** 注册时返回 400 错误：`账户名已存在`

**解决方案：**

- 这是正常现象，说明该账户名已被注册
- 使用不同的账户名进行注册
- 或使用已存在的账户名进行登录测试
