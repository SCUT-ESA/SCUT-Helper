## *Step6*.创建数据库

在 MySQL 中创建项目所需的数据库。

### 方法1：使用 MySQL 命令行（推荐）

**详细步骤：**

1. **打开命令提示符或 PowerShell**
   
   - 按 `Win + R`，输入 `cmd` 或 `powershell`，回车
   - 或者直接在开始菜单搜索 "命令提示符" 或 "PowerShell"
   
2. **登录 MySQL**
   ```bash
   mysql -u root -p
   ```
   - 按回车后，会提示输入密码
   - 输入你在 Step4 中安装 MySQL 时设置的 root 密码
   - 注意：输入密码时不会显示任何字符（这是正常的），输入完成后直接按回车

3. **执行创建数据库命令**
   登录成功后，你会看到 `mysql>` 提示符，然后执行：
   ```sql
   CREATE DATABASE IF NOT EXISTS scut_helper CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
   - 如果成功，会显示：`Query OK, 1 row affected`

4. **验证数据库创建成功**
   ```sql
   SHOW DATABASES;
   ```
   - 应该能在列表中看到 `scut_helper` 数据库
   - 如果看到，说明创建成功

5. **退出 MySQL**
   ```sql
   exit;
   ```
   或者按 `Ctrl + C`

**注意事项：**
- 如果提示 `'mysql' 不是内部或外部命令`，说明 MySQL 的 bin 目录没有添加到系统 PATH
- 解决方法：找到 MySQL 安装目录（通常在 `C:\Program Files\MySQL\MySQL Server 8.0\bin`），使用完整路径：
  ```bash
  "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p
  ```
- 或者将 MySQL 的 bin 目录添加到系统环境变量 PATH 中

### 方法2：使用 SQL 文件

**详细步骤：**

1. **打开命令提示符或 PowerShell**

2. **进入项目根目录**
   ```bash
   cd "D:\000.uniapp开发的项目\后端0"
   ```
   （替换为你的实际项目路径）

3. **执行 SQL 文件**
   ```bash
   mysql -u root -p < backend/app/init.sql
   ```
   - 按回车后，会提示输入 MySQL 密码
   - 输入密码后，会自动执行 SQL 文件
   - 这个文件会同时创建数据库和表结构

4. **验证**
   登录 MySQL 验证：
   ```bash
   mysql -u root -p
   ```
   然后执行：
   ```sql
   SHOW DATABASES;
   USE scut_helper;
   SHOW TABLES;
   ```
   应该能看到 `scut_helper` 数据库和 `users` 表

**注意事项：**
- 如果提示找不到文件，检查 `backend/app/init.sql` 文件是否存在
- 确保文件路径正确

### 验证数据库创建成功

无论使用哪种方法，最后都应该验证数据库是否创建成功：

**使用命令行验证：**
```bash
mysql -u root -p
```
```sql
SHOW DATABASES;
```
应该能看到 `scut_helper` 在列表中。

**常见问题：**

1. **提示 "Access denied"**
   - 检查用户名和密码是否正确
   - 确认 MySQL 服务已启动

2. **提示 "Can't connect to MySQL server"**
   - 检查 MySQL 服务是否启动：
     ```bash
     # Windows
     net start MySQL80
     ```
   - 或检查服务状态：
     ```bash
     sc query MySQL80
     ```

3. **数据库已存在**
   - 如果数据库已存在，可以继续下一步
   - 或者删除后重新创建：
     ```sql
     DROP DATABASE scut_helper;
     CREATE DATABASE scut_helper CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
     ```

## *Step7*.初始化数据库表

创建数据库后，需要创建表结构。

### 方法1：使用 Python 脚本（推荐）

1. 确保在 `backend/app` 目录下：
   ```bash
   cd backend/app
   ```

2. 确保已激活 conda 环境：
   ```bash
   conda activate scut_helper
   ```

3. 运行初始化脚本：
   ```bash
   python init_db_simple.py
   ```

4. 如果成功，会看到：
   ```
   ✅ 数据库表创建成功！
   ```

### 方法2：使用 SQL 文件

如果 Python 脚本执行失败，可以直接执行 SQL：

1. 登录 MySQL：
   ```bash
   mysql -u root -p
   ```

2. 执行以下 SQL：
   ```sql
   USE scut_helper;
   
   CREATE TABLE IF NOT EXISTS users (
       user_id      CHAR(36)     NOT NULL PRIMARY KEY,
       username     VARCHAR(50)  NOT NULL,
       account_name VARCHAR(20)  NOT NULL UNIQUE,
       password_hash VARCHAR(255) NOT NULL,
       created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
       updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
   ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
   ```

3. 验证表创建成功：
   ```sql
   SHOW TABLES;
   ```
   应该能看到 `users` 表

4. 退出 MySQL：
   ```sql
   exit;
   ```

## *Step8*.启动服务

### 8.1 准备工作

1. 确保已激活 conda 环境：
   ```bash
   conda activate scut_helper
   ```

2. 进入项目目录：
   ```bash
   cd "D:\000.uniapp开发的项目\后端0\backend\app"
   ```
   （替换为你的实际项目路径）

### 8.2 启动 FastAPI 服务

执行启动命令：
```bash
uvicorn main:app --reload
```

**成功标志：**
看到类似以下输出：
```
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Started reloader process
INFO:     Started server process
INFO:     Application startup complete.
```

### 8.3 访问 API 文档

服务启动后，在浏览器中访问：

- **Swagger UI（推荐）**：`http://127.0.0.1:8000/docs`
- **ReDoc**：`http://127.0.0.1:8000/redoc`
- **根路径**：`http://127.0.0.1:8000`

## *Step9*.测试 API

在 Swagger UI (`http://127.0.0.1:8000/docs`) 中测试接口：

### 9.1 测试注册接口

1. 找到 `POST /api/users/register` 接口
2. 点击 "Try it out"
3. 填写请求体：
   ```json
   {
     "username": "测试用户",
     "account_name": "testuser",
     "password": "123456"
   }
   ```
4. 点击 "Execute"
5. 如果成功，会返回 200 状态码和用户信息

### 9.2 测试登录接口

1. 找到 `POST /api/users/login` 接口
2. 点击 "Try it out"
3. 填写请求体（使用刚才注册的账户）：
   ```json
   {
     "account_name": "testuser",
     "password": "123456"
   }
   ```
4. 点击 "Execute"
5. 如果成功，会返回 200 状态码和登录成功信息
